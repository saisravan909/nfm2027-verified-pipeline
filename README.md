# nfm2027-verified-pipeline
Formal CSP models and model-checking verification suite for NFM 2027
# Formally Verified Software Supply Chain Pipelines for Autonomous Aerospace Systems

This repository contains the complete formal modeling and verification artifact for our NFM 2027 submission.

## Getting Started

### Prerequisites
- FDR4 Model Checker (Formal Systems Europe) installed and available in your system path.
- Bash shell environment.

### Running the Verification
Clone the repository and execute the verification script:
```bash
git clone [https://github.com/saisravan909/nfm2027-verified-pipeline.git](https://github.com/saisravan909/nfm2027-verified-pipeline.git)
cd nfm2027-verified-pipeline
./scripts/run_verification.sh
